# 🚀 Abhijeet Singh — Dual Identity Portfolio

A premium, interactive portfolio featuring dual-role experiences: **Full-Stack Developer** & **Visual Creator**. Built at the intersection of full-stack software engineering and high-octane video editing.

## ✨ Features

### 🏛️ Hero Split Screen
- **Interactive Split-Screen**: Smooth takeover transitions between 'Developer' and 'Creator' roles.
- **Dynamic Backgrounds**: Cinematic portrait reveals on hover with GPU-accelerated easing curves.
- **Responsive Layout**: Pixel-perfect aesthetic across desktop, tablet, and mobile.

### 💻 Developer Experience
- **ATS Resume Screener**: Project showcase highlighting automated resume parsing and matching algorithms.
- **Full-Stack Stack**: React, FastAPI, Python, PostgreSQL, Next.js, and Node.js.
- **GSAP Motion**: High-performance scroll-triggered animations.

### 🎬 Creator / Video Editing Experience
- **Visual Storytelling**: After Effects kinetic typography, Premiere Pro cinematic edits, and motion graphic previews.
- **Micro-interactions**: Custom hover effects and smooth scrolling.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Next.js, HTML5, Vanilla CSS3 (Design Tokens & Glassmorphism)
- **Backend / APIs**: Python, FastAPI, Node.js, PostgreSQL
- **Animations**: GSAP (ScrollTrigger), Lenis Smooth Scroll
- **Build Tool**: Vite 5

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/abhijeet-rx/dual-portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run local development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
